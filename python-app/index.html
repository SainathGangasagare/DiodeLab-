Important access information

The project website and interactive app are separate links

This GitHub Pages website is the DiodeLab project information and submission page. The complete interactive application—including the diode I–V Predictor, model comparisons, dataset explorer, and interactive graphs—is hosted separately on Streamlit.

To use and test the full working application, open the Streamlit link below.

Open the full interactive DiodeLab application ↗

The two websites belong to the same project, but the interactive tools run on Streamlit, not directly on this GitHub Pages page.

Research note: model outputs are estimates within the scope of the available measurements and trained models. Only recorded temperatures are presented as measured conditions; predictions outside supported device, voltage, or temperature ranges are not validated.
