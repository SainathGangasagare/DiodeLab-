# Evaluation outputs guide

These files are generated by `scripts/reproduce_evaluation.py`. Every prediction/residual table contains actual and predicted current, signed residual (`actual - predicted`) and absolute error for the listed evaluation rows. Split manifests preserve the row identifiers and split assignments used by the script.

## Folders

### `1n4004/`

- `random_split_manifest.csv`: deterministic 102/34/34 train/validation/test membership for the 170 cleaned points.
- `random_test_metrics.csv`: test-set metrics for packaged Random Forest and tuned SVR plus refitted Linear Regression and mean baselines.
- `random_test_predictions_residuals.csv`: per-row outputs for those four models.
- `random_test_residuals_vs_voltage.png`: residual plot for the random test set.
- `tuning_record.json`: 1N4004 tuning setup, notebook-selected parameters, recomputed CV result and packaged-versus-recomputed model comparison.
- `grid_search_cv_results.csv`: all 36 candidate results from the three-fold GridSearchCV rerun.
- `voltage_ordered_split_manifest.csv`: first 60% train, next 20% validation, last 20% unused by this notebook comparison.
- `voltage_ordered_validation_metrics.csv`, `voltage_ordered_validation_predictions_residuals.csv`, and `voltage_ordered_validation_residuals_vs_voltage.png`: validation results and residual evidence.

### `1n4004_reverse_bias/`

- `reverse_bias_split_manifest.csv`: 38 positive-current rows and the eight deterministic test positions.
- `reverse_bias_metrics.csv` and `reverse_bias_test_predictions_residuals.csv`: metrics and row-level evidence from the packaged original untuned reverse-bias SVR artifact.
- `reverse_bias_test_residuals_vs_voltage.png`: residual plot. The test sample is small (eight rows).

### `materials/`

- `material_multi_temperature_split_manifest.csv`: 80/20 random split membership for the final cell-348 Si/SiC workflow.
- `material_multi_temperature_test_predictions_residuals.csv`: predictions and residuals for final multi-temperature SVR and supplementary mean baselines.
- `material_multi_temperature_metrics_with_baseline.csv`: metric table; mean baseline is supplementary and not a result reported by the original notebook.
- `material_notebook_metric_comparison.csv`: generated metrics compared with the archived notebook values and notes on agreement/difference.
- `standard_material_voltage_ordered_split_manifest.csv`: outer train/test assignments for the standard Si/SiC per-device ordered experiment.
- `standard_material_tuning_split_manifest.csv`: inner fit/validation assignments inside the outer training region.
- `standard_material_tuning_grid_validation.csv`: validation MAE for all C/epsilon candidates, with the notebook-selected pair flagged.
- `standard_material_voltage_ordered_predictions_residuals.csv` and `standard_material_voltage_ordered_metrics.csv`: held-out test predictions/residuals and metrics for the standard Si/SiC SVR settings.
- `standard_silicon_voltage_ordered_residuals.png` and `standard_sic_voltage_ordered_residuals.png`: residual plots for the standard material SVR tests.
- `silicon_test_residuals_vs_voltage.png` and `sic_test_residuals_vs_voltage.png`: residual plots for the final multi-temperature SVR experiment.

## Runtime and interpretation

`run_metadata.json` at this folder's parent records the exact Python/scikit-learn versions, whether the scikit-learn pin matched, whether a diagnostic override was used, warnings observed while loading serialized estimators and key interpretation caveats.

The current packaged outputs were generated using Python 3.13.5 / scikit-learn 1.8.0, while the project declares Python 3.11 / scikit-learn 1.6.1. They are diagnostic evidence, not a strict pinned-version reproduction. The 1N4004 metrics reproduce the notebook values to displayed precision; standard Silicon ordered metrics also match to displayed precision; SiC comparisons show small differences and are flagged in their comparison records. Re-run with the project pin before calling all values exactly reproduced.

The script does not recreate every saved estimator from raw data. It loads packaged 1N4004 and reverse-bias estimators for those evaluations and refits material models according to the documented notebook cells. See `docs/REPRODUCIBILITY.md` for boundaries.
